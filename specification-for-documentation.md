Specifikacija projektne dokumentacije
Dokumentacija treba da sadrži sledeće stavke:
1. Uvod
○ Kratko predstavljanje projekta.
2. Opis korišćenih tehnologija
○ Tehnologije korišćene za razvoj baze podataka, backend i frontend delova projekta.
3. Opis procesa izrade projekta
○ Struktura baze podataka (tabele, ključni entiteti).
○ Backend logika (arhitektura, API rute, integracije).
○ Frontend deo (struktura aplikacije, komponente, stilizacija).
4. Funkcionalnosti aplikacije
○ Pregled glavnih funkcionalnosti.
○ Način korišćenja aplikacije iz perspektive korisnika.
5. Zaključak
○ Kratak osvrt na tok izrade projekta.
○ Moguća buduća unapređenja ili nadogradnje.
